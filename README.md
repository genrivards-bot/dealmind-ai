# DealMind AI — Android-friendly starter package

Это исходный прототип, а не уже опубликованный SaaS.

## Что внутри
- `frontend/index.html` — простая демонстрационная страница на русском.
- `backend/app.py` — минимальный API на FastAPI для проверки состояния и демо-обработки текста.
- `backend/requirements.txt` — зависимости.

## Важно
Для работы сервера нужен компьютер или облачная среда. Сам ZIP на телефоне не запускает сайт.
Настоящая AI-обработка потребует API-ключа провайдера, который нужно хранить только на сервере.
Не отправляйте API-ключи в чат.

## Запуск (если появится доступ к облачной среде или ПК)
Из папки `backend`:
    pip install -r requirements.txt
    uvicorn app:app --host 0.0.0.0 --port 8000

Это демонстрационный каркас. Перед приёмом реальных документов и оплатой нужны авторизация,
изоляция данных компаний, безопасное хранение файлов, резервные копии и юридическая проверка.
